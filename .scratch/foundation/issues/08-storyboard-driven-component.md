# 08: 分镜驱动组件

**What to build:** 一期有一份分镜 JSON：每个画面列出用到的组件和参数，并写出若干动画触发，每个触发是"旁白句 ID + 偏移秒数（可以为负）+ 动作"；分镜还可以覆盖个别位置的停顿。分镜里不出现绝对时间（ADR-0003）。渲染前用 zod 校验分镜，引用了不存在的旁白句 ID 或组件名时报错，并指出具体位置。有一个组件注册表，样片里有一个简单组件，按分镜在指定的旁白句出现，并带淡入或位移动画。

**Blocked by:** 03

**Type:** AFK

**Status:** ready-for-agent

- [ ] 分镜的 zod schema，加上交叉校验：旁白句 ID 必须存在于合成清单，组件名必须在注册表里
- [ ] 时间轴支持分镜里的停顿覆盖，覆盖优先于默认规则
- [ ] 动画触发帧 = 旁白句开始帧 + 偏移；偏移为负数时可以提前
- [ ] 一个简单组件，在分镜指定的旁白句出现
- [ ] TS 测试覆盖：停顿覆盖、负偏移、ID 不存在和组件名不存在时的报错
