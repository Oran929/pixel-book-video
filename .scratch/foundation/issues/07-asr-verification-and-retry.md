# 07: 语音识别复核与重试

**What to build:** 每句配音生成后，由本地 MLX 版 Whisper 转回文字，与朗读文本（读音替换之后的文本，或手写的 `speech`）对比，不再和字幕文本对比。对比前，两边都先规范化：去掉标点和空白，统一全角和半角。因为对比对象已经是读音替换后的朗读文本，规范化不再按读音表做等价替换。差异率超过阈值就重新生成；重试几次仍然不通过，就在检查报告里标记给我。阈值和重试次数可以配置。

**Blocked by:** 04

**Type:** AFK（阈值和重试次数的初始值，要先和我确认）

**Status:** ready-for-agent

- [ ] 语音识别引擎作为适配器传入：测试用假引擎（可以设定某句返回错误文字，或者"前几次错、之后对"），真实运行用 MLX Whisper
- [ ] 规范化规则可以测试，并且不会把格式差异误判为失败
- [ ] 重试后通过的句子，用通过的那一版写入缓存
- [ ] 超过重试次数的句子出现在检查报告里，附带字幕文本、朗读文本、识别结果、差异率
- [ ] 复核通过的结果也缓存起来，缓存命中的句子不再重复识别
- [ ] 用真实 Whisper 跑一遍样例旁白稿，记录误报和漏报的情况，作为确定阈值的依据
- [ ] Python 测试覆盖：通过、重试后通过、最终失败、规范化等价
- [ ] Python 测试：手写了 `speech` 的句子（识别结果与 `speech` 一致、与字幕文本不同）能正常通过
