# 08: 分镜驱动组件

**What to build:** 一期有一份分镜 `books/<书>/<章>/<期>/storyboard.json`：每个画面列出用到的组件和参数，并写出若干动画触发，每个触发是"旁白句 ID + 偏移秒数（可以为负）+ 动作"；分镜还可以覆盖个别位置的停顿。分镜里不出现绝对时间（ADR-0003）。渲染前用 zod 校验分镜，引用了不存在的旁白句 ID 或组件名时报错，并指出具体位置。有一个组件注册表，样片里有一个简单组件，按分镜在指定的旁白句出现，并带淡入或位移动画。

**Blocked by:** 03

**Type:** AFK

**Status:** ready-for-agent

**格式约定（2026-10-28 审查后补充）：**

- 动作先只有一种：`enter`（出现），带一个动画参数 `fade`（淡入）或 `slide`（位移）。组件从触发帧开始显示，到所在画面结束时消失。
- 触发帧 = 旁白句开始帧 + 偏移秒数 × 帧率，四舍五入到整帧。
- 触发引用的旁白句必须属于同一个画面；触发帧早于所在画面的开始帧时报错（不悄悄截断）。
- 停顿覆盖写成 `{ "after": "<旁白句ID>", "seconds": 1.2 }`，表示这句之后的停顿；秒数必须 ≥ 0，换算成帧时与默认停顿一样四舍五入。
- 分镜由 03 的 `stage` 命令复制到 `video/public/episode/storyboard.json`，Remotion 和读合成清单一样，用 `fetch(staticFile())` 读取。没有分镜文件时，照常渲染（只有字幕），03 的路径不受影响。

**验收：**

- [ ] 分镜的 zod schema，加上交叉校验：旁白句 ID 必须存在于合成清单并属于该画面，组件名必须在注册表里，报错信息指出是第几个画面、第几个触发
- [ ] 时间轴支持分镜里的停顿覆盖，覆盖优先于默认规则
- [ ] 动画触发帧按上面的规则计算；偏移为负数时可以提前，但不能早于画面开始
- [ ] 一个简单组件，在分镜指定的旁白句出现
- [ ] 样例书的分镜 `books/sample/ch01/ep01/storyboard.json` 提交到 git
- [ ] TS 测试覆盖：停顿覆盖、负偏移、偏移取整、触发早于画面开始时报错、ID 不存在和组件名不存在时的报错、旁白句不属于该画面时的报错
