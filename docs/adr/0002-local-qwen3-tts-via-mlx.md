# 配音使用本机 Qwen3-TTS 1.7B（bf16，通过 mlx-audio 运行）

配音完全在本机离线生成，零费用，Apache 2.0 许可可以商用，并且用 Base 模型克隆参考音频，保证一个系列的声音一致。我们选 1.7B 而不是 0.6B，选 bf16 而不是量化版本，因为是离线生成，只看效果、不在乎速度，M5 Max 的内存完全够用。

## Considered Options

- **edge-tts**：零配置，但必须联网；而且它不是微软官方开放的接口，可能被限制，商用也处于灰色地带。
- **IndexTTS2 / CosyVoice 3**：效果好，但主要面向 NVIDIA 显卡，在 Mac 上部署麻烦。
