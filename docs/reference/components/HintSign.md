# 提示牌 `HintSign`

- **效果**：书里的提示框：橙色标题牌写「提示」和编号，下面是大号的提示标题，入场时闪一下亮起
- **适合表达**：书里的某条提示（「提示14 ETC」）

## 调用示例

```json
{ "id": "tip", "component": "HintSign", "props": { "label": "提示", "number": "14", "title": "ETC" }, "at": [1, 1] }
```

## 参数

| 参数 | 类型 | 必填 | 取值范围 | 显示文字 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `label` | 字符串 | 必填 | 不空 | 是 | 标题牌上编号前的字（字号 `subtitle`）。「提示」两个字也由它传入，组件里不写死 |
| `number` | 字符串 | 必填 | 不空 | 是 | 提示的编号，字符串，例如 `"14"`；画面说明里写了「提示14」才能用 |
| `title` | 字符串 | 必填 | 不空 | 是 | 下面的大号提示标题（字号 `large`，单行） |

「显示文字」参数的值必须出自本画面的画面说明或旁白句（见 `docs/reference/storyboard.md`「显示文字」）；字放不下怎么算见 `docs/reference/storyboard.md`「字宽估算」。

标题和标题牌最多 660 像素（约 6 个汉字），放不下报错。这个宽度是格子宽减去两侧粗描边、硬阴影偏移和两侧内边距，汉字数按大号字算。

## 占几格

5 列 × 3 行。

## 状态

第一个状态是初始状态。切到某个状态时放表里的音效（入场时只放入场音效，不放初始状态的音效；之后切回初始状态时才放）。

| 状态 | 画面上 | 切到时的音效 |
| --- | --- | --- |
| `normal`（初始） | 只有这一个状态 | 不放 |

## 入场和退场动画

- 入场默认 `light`，退场默认 `fade`（分镜不写 `animation` 时）。
- 都能用通用动画 `fade`、`slide`、`none`，以及只有这个组件能用的特殊效果 `light`（0.8 秒）。取值见 `docs/reference/storyboard.md`「分镜」。

入场默认是它自己的特殊效果 `light`（亮起，`MOTION.hintLightSeconds` 0.8 秒）：牌子先是暗的（`COLOR.hintUnlit`），闪一下、灭掉，从一半起亮住，外面扩出一圈黄光（`COLOR.hintGlow`）后消失。退场写 `animation: "light"` 时倒着播，即熄灭。

## 音效

入场 `ding`，退场 `leave`；切到各状态的音效见「状态」。音效 ID 见 `docs/reference/storyboard.md`「音效」。

## 嵌套

整块都是字（`labelArea` 是整块），不能嵌子组件。
