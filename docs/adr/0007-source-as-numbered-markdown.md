# 原文由本地脚本转换成带段落编号的 Markdown，出处一律引用段落编号

EPUB 和文字版 PDF 都用本地脚本（EPUB 用 pandoc 或直接解析 HTML，PDF 用 pymupdf4llm 一类的库）机械地转换成 Markdown，不经过模型，也不花 token；Claude 只读转换结果。段落编号格式为 `ch02-¶017`，每章从 1 开始。正文段落、列表项、代码块、引文框各算一段，标题不编号。转换脚本固定，不手工修改转换结果，这样重新转换时编号不会变，旁白稿里的出处也就不会错位。原书文件和转换出来的全文受版权保护，都不提交到 git，需要时从原书重新生成；转换脚本本身提交到 git。

## 修订（2026-10-29）：图片也占段落编号

《程序员修炼之道》的 EPUB 里，代码块都是图片，没有文字。所以「代码块各算一段」改为：**每张图片各算一段**，内容是占位符（例如 `[图 images/00005.jpeg]`），和文字段落一起连续编号。旁白句不能只引用图片段，因为没有文字可以核对，机械层会报错；但可以和文字段一起引用。这样编号完整，语义核对时也知道原文这里有一段代码；以后加 OCR，编号也不用变。脚注作为编号段落追加在该章末尾；前言、赞誉、跋、练习参考答案不转换。
