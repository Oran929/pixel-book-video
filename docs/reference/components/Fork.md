# 岔路 `Fork`

- **效果**：一个路口分出几条路，可以把某条路铺成黄色，或在某条路上放下路障
- **适合表达**：选择、分岔、哪条路好走：ETC 向导站在分岔口、看不出哪条路好改、整块替换时没有路障

## 调用示例

```json
{ "id": "fork", "component": "Fork", "props": { "roads": 3, "labels": ["好改", "难改", "看不出"] }, "at": [5, 1] }
```

## 参数

| 参数 | 类型 | 必填 | 取值范围 | 显示文字 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `roads` | 整数 | 必填 | 2–4 | 否 | 几条路，从上往下数，第 1 条在最上面：左边一段路进路口，分岔的竖路往右分出这几条路 |
| `labels` | 字符串数组 | 可选 | 每项不空 | 是 | 每条路的标签，项数必须等于 `roads`；字号 `subtitle`，写在路障右边，最多 480 像素（约 10 个汉字），按 `forkLabelRoom()` 算，放不下报错。不写就是不带字的路 |

「显示文字」参数的值必须出自本画面的画面说明或旁白句（见 `docs/reference/storyboard.md`「显示文字」）；字放不下怎么算见 `docs/reference/storyboard.md`「字宽估算」。

## 占几格

6 列 × 4 行。

## 状态

第一个状态是初始状态。切到某个状态时放表里的音效（入场时只放入场音效，不放初始状态的音效；之后切回初始状态时才放）。

| 状态 | 画面上 | 切到时的音效 |
| --- | --- | --- |
| `normal`（初始） | 什么都没有 | `blip` |
| `mark-1` | 标出第 1 条路：路面从路口往右铺成黄色 | `blip` |
| `mark-2` | 标出第 2 条路：路面从路口往右铺成黄色 | `blip` |
| `mark-3` | 标出第 3 条路：路面从路口往右铺成黄色 | `blip` |
| `mark-4` | 标出第 4 条路：路面从路口往右铺成黄色 | `blip` |
| `block-1` | 在第 1 条路上放路障：红白条纹的路障从上方落下 | `drop` |
| `block-2` | 在第 2 条路上放路障：红白条纹的路障从上方落下 | `drop` |
| `block-3` | 在第 3 条路上放路障：红白条纹的路障从上方落下 | `drop` |
| `block-4` | 在第 4 条路上放路障：红白条纹的路障从上方落下 | `drop` |

序号不能超过 `roads`（见 `docs/reference/storyboard.md`「带序号的状态」）。一次只处在一个状态：从 `block-N` 切到别的状态就是撤掉路障（路障抬起消失），所以「标出一条路，同时另一条有路障」表现不了，要的话再加状态。动画都用一个通用动画的时长。

## 入场和退场动画

- 入场默认 `fade`，退场默认 `fade`（分镜不写 `animation` 时）。
- 都能用通用动画 `fade`、`slide`、`none`。取值见 `docs/reference/storyboard.md`「分镜」。

## 音效

入场 `pop`，退场 `leave`；切到各状态的音效见「状态」。音效 ID 见 `docs/reference/storyboard.md`「音效」。

## 嵌套

写了 `labels` 时整块都算标签（`labelArea`），不能嵌子组件；不写字时可以嵌。

## 细节

颜色（`COLOR.fork*`）、尺寸（`SIZE.fork*`）在风格表里，风格样张的「用途色」一节能看到。

## 样张

Studio 里的 `Sample-Fork`：四条带字的路逐条标出、逐条放路障、撤掉、退场；两条、三条不带字的路三种入场和退场动画。
