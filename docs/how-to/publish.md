# 发布一期

关口 3 通过（`pixelbook status` 报 `done`）之后，发到视频平台要准备三样，都从期目录 `books/<书>/chNN/epNN/` 取：

- **成片**：`out/<书>-<章>-<期>.mp4`（关口 3 通过的那一版）。
- **简介**：写明原书的书名、作者、出版社，照 `books/<书>/book.yaml` 抄。`out/` 里有 `credits.txt`（用了 CC-BY 配乐）时，把它那一行原样贴进简介；没有就不用贴。
- **分段**：`out/segments.txt` 原样贴到视频平台的分段设置（第一行是 `00:00 片头`，片尾不列）。
