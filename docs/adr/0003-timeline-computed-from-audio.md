# 时间轴由代码根据音频时长计算，分镜里不写绝对时间

时间轴要求稳定、可重复，不能依赖模型的判断。每个旁白句的时长就是它的音频时长（用 ffprobe 测量）。句间停顿和画面之间的停顿由代码中的固定规则决定，个别位置可以在分镜里覆盖。每句的开始时间由渲染前的代码累加算出。Claude 写分镜时只写"哪个画面、哪个组件、哪个旁白句 ID、偏移多少秒"，从不写绝对秒数。因此改一句旁白、重新配音之后，时间轴会自动重算，分镜不用改。

## Consequences

- 动画只能以旁白句为锚点，再加上一个可选的偏移量。不做逐字对齐，因为 Qwen3-TTS 不提供字级时间戳。
- Python 只输出每句单独的 wav 和时长，不拼接正式音轨；拼接只在试听时使用。
- 旁白句 ID 只是身份标识，在创建时分配一次，以后不再重新编号；播放顺序以旁白稿里的排列为准。
