# 电脑 `Computer`

- **效果**：一台老式显示器加底座，屏幕上有字，能崩溃成蓝屏也能重启
- **适合表达**：电脑、程序出错或崩溃：柯克船长的开场（s04-c01）和 s05-c03 前后呼应

## 调用示例

```json
{ "id": "computer", "component": "Computer", "props": { "screen": ["两条", "自相矛盾的知识"] }, "at": [7, 1] }
```

## 参数

| 参数 | 类型 | 必填 | 取值范围 | 显示文字 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `screen` | 字符串数组 | 必填 | 最多 3 项，每项不空 | 是 | 屏幕上的字，一项一行，可以是空数组（屏幕上没有字）。每行字号 `subtitle`，最多 448 像素（约 9 个汉字），放不下报错。屏幕上要出现「ERROR」之类的字，也要写进 `screen` |

「显示文字」参数的值必须出自本画面的画面说明或旁白句（见 `docs/reference/storyboard.md`「显示文字」）；字放不下怎么算见 `docs/reference/storyboard.md`「字宽估算」。

## 占几格

4 列 × 4 行。

## 状态

第一个状态是初始状态。切到某个状态时放表里的音效（入场时只放入场音效，不放初始状态的音效；之后切回初始状态时才放）。

| 状态 | 画面上 | 切到时的音效 |
| --- | --- | --- |
| `normal`（初始） | 深色屏幕绿字，最后一行后面一个光标一亮一灭 | `blip` |
| `crashed` | 切过来的 0.8 秒里左右抖动、红白闪屏、冒出花屏横条，之后停在蓝屏，每行字比上一行往下错开一点，横向不动 | `crash` |

可以从 `crashed` 切回 `normal`（重启）。

## 入场和退场动画

- 入场默认 `fade`，退场默认 `fade`（分镜不写 `animation` 时）。
- 都能用通用动画 `fade`、`slide`、`none`。取值见 `docs/reference/storyboard.md`「分镜」。

## 音效

入场 `pop`，退场 `leave`；切到各状态的音效见「状态」。音效 ID 见 `docs/reference/storyboard.md`「音效」。

## 嵌套

上面三行格是屏幕（`labelArea`），子组件只能嵌在底座那一行。

## 细节

颜色（`COLOR.computer*`）、尺寸（`SIZE.computer*`）、时长（`MOTION.computerCrashSeconds` 等）都在风格表里；提示牌和电脑增补的颜色在风格样张的「用途色」一节里能看到。
