# 一本书独有的东西都在书的目录下，命令生成的放进期目录的 `out/`

到 ep01 为止，成片、配乐声轨、试听混音、新术语试听都写进仓库根目录的 `out/`，文件名靠 `<书>-<章>-<期>` 区分。合成清单、检查报告、时间轴、打点时间表、配乐署名则直接写在期目录里，和旁白稿、语义核对结果、分镜混在一起。实验产物也堆在根目录的 `out/`（到 ep01 时 237M），找一期的成片要在一堆试验文件里翻。

改成按归属放：

- **所有书共用的**放在 `video/`、`voices/`、`tools/`，不放在任何一本书的目录里。
- **某一本书独有的**都在 `books/<书>/` 下：书的配置和音色锁定、原书和转换结果、配音缓存、每章的大纲、每期的期目录。
- 期目录里分两部分。`out/` 之外是这一期的**内容**（旁白稿、语义核对结果、分镜），要提交。`out/` 是**产物目录**，放命令为这一期生成的全部文件（成片、配乐声轨和参照、试听混音、新术语试听、合成清单、检查报告、时间轴、打点时间表、配乐署名），不提交，删掉以后可以重新生成。
- 成片文件名保留完整 ID（`<书>-<章>-<期>.mp4`），拖出目录上传时也不会重名。
- 仓库根目录不再有 `out/`。不属于任何一本书的音色试听写到 `voices/audition/`，不提交。

## Considered Options

- **书级别的 `books/<书>/out/chNN/epNN/`**：一本书的产物集中在一处，但同一期的内容和产物分在两棵目录树里，章、期的目录结构要维护两份。
- **产物直接写在期目录里，不建 `out/`**：内容和产物混在一起，`.gitignore` 要一个个列文件名。想清掉产物重新生成时，也分不清哪些文件能删。
- **保留根目录的 `out/`**：一期的东西分散在两处，按书归类找起来不方便，这正是这次要解决的问题。

## Consequences

- 每个写文件的命令（配音、时间轴导出、渲染、试听混音、新术语试听）默认都写进期目录的 `out/`，期目录只读不写。Remotion 仍然从 `video/public/episode/` 读复制过去的文件，这一点不变。
- `.gitignore` 里列期目录生成文件的那几条规则，收成一条 `books/*/*/*/out/`。
- 已经做过的期，把期目录里原来的生成文件挪进 `out/`（或者直接重新生成）。
