# 画面上只常驻字幕和左上角小标题，其余元素都由分镜按期调用通用组件

样片做完后回顾（2026-10-28），最有效的调整是把不必要的常驻元素都改成通用组件：比如 Q 版小人原来打算常驻画面，现在是分镜需要"人物做什么"时才调用；左上角的小标题也定为这一期的书名或主题名，而不是写死的频道名。以后每期都按这个原则做：画面上常驻的只有字幕和左上角小标题，其他元素都按当期内容，在分镜里调用通用组件。这样画面更干净，每期也只出现和内容有关的东西。

这推翻了 foundation spec 里"外壳"一层的设想。原计划在阶段 4 常驻四角取景框、HUD、段标题卡、右上角段进度等；阶段 4 的 spec 要据此重写，这些元素要么不做，要么做成分镜按需调用的通用组件。

## Consequences

- 加新的画面元素时，默认做成通用组件（参数格式登记在 `video/src/components/schemas.ts`），由分镜触发，不加进常驻的画面层。
- 术语表里"外壳"的含义随之收窄，只剩字幕和左上角小标题（代码在 `video/src/shell/`）。

## 修订（2026-10-29）：「外壳」作废，字幕和主题改成常驻组件

阶段 3 的拷问里，「外壳」被重新理解成**风格**：调色配方、字体、像素网格、描边和阴影规则，决定所有组件的样子。所以这个词不再用于画面元素：
- 字幕和左上角的小标题改成**常驻组件**：每期默认都有，分镜不用调用，样子由风格决定（例如换字体）。代码从 `video/src/shell/` 挪到 `video/src/components/`。
- 左上角固定显示大纲给这一期定的**主题**，不再显示书名（书名写在简介里）。
- 目前全频道只有一套风格，不做切换机制，等真要做第二套时再加。

「只常驻这两样」的原则不变。
