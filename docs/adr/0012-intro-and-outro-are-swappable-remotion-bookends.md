# 片头片尾是 Remotion 一侧可替换的固定动画，按项目配置从登记表里选

取代 [ADR-0010](0010-fixed-outro-appended-at-voicing.md)。

用户自己做好了片头（#50）和片尾（#51）两段 Remotion 动画，各自带音轨；片尾的三句固定台词（「本期先讲到这里，欢迎大家阅读原著了解更原汁原味的内容，我们下一期见」）已经录在片尾的音轨里，字幕框也画在动画里（spec #16「修订二」「修订三」）。所以 ADR-0010 的 TTS 旁白片尾整个去掉：`pixelbook voice` 不再往旁白稿后面追加片尾段，合成清单里没有保留 ID `outro`、`outro-c01`、`outro-l01`……，旁白稿也可以自由使用这些 ID。

整期结构是**片头 + 正片 + 片尾**，片头片尾只在 Remotion 一侧接上，Python 不知道它们的内容：

- 片头、片尾各有一张登记表（`video/src/intro/intros.ts`、`video/src/outro/outros.ts`），ID → 标题、帧数、音轨，和配乐库一样在导入时校验；动画组件按同样的 ID 登记在旁边。现在各登记用户做的这一个（片头 `load-pixel-book` 422 帧，片尾 `bye-bye` 324 帧）。
- 项目配置 `video/src/project-config.ts` 写用哪个片头、哪个片尾，也可以写「不用」（`null`）。`planEpisode`、时间轴的 `totalFrames`、帧数核对和时长判断都按选中的那一个的帧数算，不写死。
- 正文到最后一句音频结束为止，片尾紧接着开始；时间轴记 `introFrames`、`outroFrames`，最后一个画面和段到片尾开始为止。
- 片头片尾期间不显示字幕和主题；它们自带的音轨原样放。配乐从片头结束开始，在**正文**最后 2 秒淡出，不覆盖片头和片尾。
- 片头片尾不是分镜组件：不占网格、没有状态，不进组件目录，不受组件目录的风格表和显示文字检查约束（它们是用户定稿的作品）。

## Considered Options

- **保留 TTS 片尾，再叠上片尾动画**：同一句话会念两遍，动画里也已经有字幕框。
- **片尾动画接在合成清单里，作为最后一段**（ADR-0010 的做法）：动画的时长、配音都是固定的，不需要 Python 配音和复核；放进合成清单只会让 Python 多知道一段它不处理的内容，时间轴和分镜还要绕开它。
- **片头片尾写死在代码里**（#50 时片头的做法）：换片头片尾要改时间轴、渲染多处代码。做成登记表加项目配置之后，换一个只要登记、改配置两步，开源后别人也能换成自己的。

## Consequences

- 已经配过音的期目录里，旧的合成清单还带着 TTS 片尾段；重新运行 `pixelbook voice` 就去掉了（正文全部命中配音缓存）。
- 打点时间表仍然不列片尾（每期都一样），第一行仍是 `00:00 片头`（用了片头时）。
- `pixelbook check` 的估算时长只算旁白稿，不含片头片尾（现在共约 25 秒）。
- 片尾的三句台词由用户录好、混进音轨，不走锁定音色、配音缓存和语音识别复核；换书换音色时片尾的声音不跟着变。
