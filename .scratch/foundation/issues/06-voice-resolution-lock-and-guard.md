# 06: 音色解析、锁定与守卫

**What to build:** 书的音色 = 项目默认音色，除非书的配置里有覆盖。一本书第一次正式配音时，流水线把解析出的实际音色设置（不是"跟随默认"这个引用）写入锁定音色文件。之后每次配音前，守卫比较"当前解析出的音色"和锁定音色；两者不一致时拒绝运行，并说明不一致的地方和两个选项（改回原来的音色，或者整本书重新配音）。使用显式的重新配音参数时，更新锁定，整本书用新音色重新生成（ADR-0005）。

**Blocked by:** 02、05

**Type:** AFK

**Status:** ready-for-agent

- [ ] 书配置里可以覆盖音色；不覆盖时使用项目默认音色
- [ ] 首次正式配音时写入锁定音色，内容是完整的音色设置和参考音频指纹
- [ ] 项目默认音色改了、或书的覆盖设置改了之后，守卫拒绝运行，提示信息列出锁定值和当前值
- [ ] 加上重新配音参数后可以通过：锁定被更新，所有句子按新音色重新生成
- [ ] 新术语试听、音色试听这类试听命令不受守卫限制，也不写入锁定
- [ ] Python 测试覆盖以上各种情况
