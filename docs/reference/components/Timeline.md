# 时间线 `Timeline`

- **效果**：一条横轴加几个带字的节点，节点从左往右逐个点亮
- **适合表达**：先后顺序、进度：开发时间线、工程日志

## 调用示例

```json
{ "id": "timeline", "component": "Timeline", "props": { "nodes": ["起点", "开发过程", "发布"] }, "at": [3, 2] }
```

## 参数

| 参数 | 类型 | 必填 | 取值范围 | 显示文字 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `nodes` | 字符串数组 | 必填 | 2–6 项，每项不空 | 是 | 节点下面的字，从左往右一项一个节点。字号 `subtitle`，每项最多 264 像素（约 5 个汉字），按 `timelineLabelRoom()` 算，放不下报错 |

「显示文字」参数的值必须出自本画面的画面说明或旁白句（见 `docs/reference/storyboard.md`「显示文字」）；字放不下怎么算见 `docs/reference/storyboard.md`「字宽估算」。

## 占几格

每个节点 2 列，所以 `2 × 节点数` 列 × 2 行（上一行横轴和节点，下一行字）。

## 状态

第一个状态是初始状态。切到某个状态时放表里的音效（入场时只放入场音效，不放初始状态的音效；之后切回初始状态时才放）。

| 状态 | 画面上 | 切到时的音效 |
| --- | --- | --- |
| `normal`（初始） | 一个都没点亮 | 不放 |
| `lit-1` | 点亮了前 1 个节点 | `ding` |
| `lit-2` | 点亮了前 2 个节点 | `ding` |
| `lit-3` | 点亮了前 3 个节点 | `ding` |
| `lit-4` | 点亮了前 4 个节点 | `ding` |
| `lit-5` | 点亮了前 5 个节点 | `ding` |
| `lit-6` | 点亮了前 6 个节点 | `ding` |

序号不能超过节点数（见 `docs/reference/storyboard.md`「带序号的状态」）。从点亮较少的状态切到 `lit-N` 时，横轴从上次亮到的地方沿着往右亮过去（每多一个节点多 0.4 秒），亮光走到的节点变黄、字变深；熄灭（切到较少的 `lit-N` 或 `normal`）是一下子变的。

## 入场和退场动画

- 入场默认 `fade`，退场默认 `fade`（分镜不写 `animation` 时）。
- 都能用通用动画 `fade`、`slide`、`none`。取值见 `docs/reference/storyboard.md`「分镜」。

## 音效

入场 `pop`，退场 `leave`；切到各状态的音效见「状态」。音效 ID 见 `docs/reference/storyboard.md`「音效」。

## 嵌套

下一行是字（`labelArea`），子组件只能嵌在横轴那一行。

## 细节

颜色（`COLOR.timeline*`）、尺寸（`SIZE.timeline*`）在风格表里，风格样张的「用途色」一节能看到。

## 样张
