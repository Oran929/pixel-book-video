# 组件目录

写分镜能用的组件。先在下表挑组件，再读选中组件的详情页（参数、占几格、状态、入场和退场动画、音效、调用示例），分镜里用 `component` 写组件名来调用。

本目录由 `cd video && npm run catalog` 从组件声明（`video/src/components/*-declaration.ts`）生成，不要手改；`npm run test` 检查它和声明一致。

| 组件 | 效果 | 适合表达 |
| --- | --- | --- |
| [知识块 `PixelBlock`](PixelBlock.md) | 一个带字的像素方块，从上方落下，可以高亮或标成已改 | 书里的一个概念、一段知识、一份东西（代码、文档、数据库 Schema）；落下、复制、高亮、只改了一处 |
| [小人 `Mascot`](Mascot.md) | Q 版频道小人，一个或一群，头顶能冒问号或感叹号 | 人物做什么：一群上师和大神、程序员头顶冒问题、恍然大悟 |
| [箭头 `Arrow`](Arrow.md) | 一支粗箭头从一个组件长出来，指到另一个组件，可以高亮 | 指向、依赖、牵连：「指向 ETC」「改一处要连带改三处」 |
| [提示牌 `HintSign`](HintSign.md) | 书里的提示框：橙色标题牌写「提示」和编号，下面是大号的提示标题，入场时闪一下亮起 | 书里的某条提示（「提示14 ETC」） |
| [电脑 `Computer`](Computer.md) | 一台老式显示器加底座，屏幕上有字，能崩溃成蓝屏也能重启 | 电脑、程序出错或崩溃：柯克船长的开场（s04-c01）和 s05-c03 前后呼应 |
| [岔路 `Fork`](Fork.md) | 一个路口分出几条路，可以把某条路铺成黄色，或在某条路上放下路障 | 选择、分岔、哪条路好走：ETC 向导站在分岔口、看不出哪条路好改、整块替换时没有路障 |
| [时间线 `Timeline`](Timeline.md) | 一条横轴加几个带字的节点，节点从左往右逐个点亮 | 先后顺序、进度：开发时间线、工程日志 |

## 通用规则

- 动作和 `animation` 的取值见 `docs/reference/storyboard.md`「分镜」，摆放见同一份的「网格」「嵌套」，字放不下怎么算见「字宽估算」，显示文字的出处见「显示文字」，音效 ID 见「音效」。
- 入场时组件处在**第一个状态**（初始状态），只响入场音效；之后切回初始状态时才响初始状态的音效。音效写「不放」的，切到那个状态时没有声音。
- 入场、退场都能用通用动画 `fade`、`slide`、`none`；详情页写的是不写 `animation` 时用的默认动画，和组件自己的特殊效果。
- 「显示文字」参数的值必须出自本画面的画面说明或旁白句。
- 常驻组件（字幕、左上角的主题）和片头片尾不是分镜组件，不在这里。
- 所有组件依次演一遍的样片：合成 `ComponentSamples`（把每个组件的 `Sample-<组件名>` 首尾相接），`cd video && npx remotion render ComponentSamples out/component-samples.mp4`。
