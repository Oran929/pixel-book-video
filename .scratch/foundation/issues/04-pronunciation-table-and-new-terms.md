# 04: 读音表与新术语

**What to build:** 有一份全频道共用的读音表（术语 → 朗读写法）。配音流水线生成朗读文本时，按读音表机械替换；旁白句如果手写了 `speech`，就以手写的为准。流水线会自动找出新术语，也就是字幕文本里由英文字母、数字或符号组成、但读音表里没有、且所在旁白句没有手写 `speech` 的片段，列成清单。有一个命令，为每个新术语单独生成一小段试听音频。只要还有未处理的新术语，正式配音就拒绝运行。

**Blocked by:** 03

**Type:** AFK

**Status:** ready-for-agent

- [ ] 读音表放在仓库根目录，按 02 记录下的读错术语建立初始条目
- [ ] 替换结果确定，长术语优先匹配（例如 "KV Cache" 先于 "KV"）
- [ ] 手写的 `speech` 优先，不套用读音表
- [ ] 新术语清单报告每个术语出现在哪些旁白句
- [ ] 新术语试听命令为每个术语生成一段音频，文件名能看出是哪个术语
- [ ] 有新术语时，流水线返回"拒绝运行"并列出这些术语，不生成任何配音
- [ ] Python 测试覆盖：替换、长词优先、手写优先、新术语检测、拒绝运行
