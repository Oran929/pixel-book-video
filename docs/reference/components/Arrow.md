# 箭头 `Arrow`

- **效果**：一支粗箭头从一个组件长出来，指到另一个组件，可以高亮
- **适合表达**：指向、依赖、牵连：「指向 ETC」「改一处要连带改三处」

## 调用示例

```json
{ "id": "dry-etc", "component": "Arrow", "props": {}, "from": "dry", "to": "etc" }
```

## 参数

没有参数，`props` 写 `{}`。

## 占几格

不占格子，不参加重叠检查：这是连线类组件，不写 `at`、不写 `parent`，`from`、`to` 必须都写，必须是本画面里两个不同的、按格子摆放的组件（不能指向另一个连线类组件），画法按两端组件的位置算。不是连线类组件的写了 `from`、`to` 也报错。

## 状态

第一个状态是初始状态。切到某个状态时放表里的音效（入场时只放入场音效，不放初始状态的音效；之后切回初始状态时才放）。

| 状态 | 画面上 | 切到时的音效 |
| --- | --- | --- |
| `normal`（初始） | 深色 | `blip` |
| `highlight` | 黄色的芯加深色描边 | `blip` |

## 入场和退场动画

- 入场默认 `fade`，退场默认 `fade`（分镜不写 `animation` 时）。
- 都能用通用动画 `fade`、`slide`、`none`。取值见 `docs/reference/storyboard.md`「分镜」。

入场时箭杆从起点长到终点（按入场进度），外面再套入场动画。

## 音效

入场 `pop`，退场 `leave`；切到各状态的音效见「状态」。音效 ID 见 `docs/reference/storyboard.md`「音效」。

## 细节

- **时间**：箭头在画面上的区间（从入场帧到退场动画播完，没有退场的到画面结束）必须完全落在两端组件各自的区间里：和端点同一帧入场、同一帧离开画面都合法；早于某一端入场，或某一端已经离开画面时箭头还在，都报错（报出第几个画面、第几个组件、箭头和那一端的帧区间）。端点退场时，箭头要一起退场（同样长的退场动画，或更早）。
- **画法**：沿两端矩形中心的连线，从起点组件的边框外 `SIZE.arrowGap` 出发，尖停在终点组件边框外 `SIZE.arrowGap`；粗箭杆（`SIZE.strokeThick`）加三角形箭头头（`SIZE.arrowHeadLength`、`SIZE.arrowHeadHalfWidth`），坐标取整到像素网格，不抗锯齿。两端挨得太近、放不下箭头头时不画。端点在网格上怎么摆，箭头就怎么斜，所以摆放时两端之间要留出空档，箭杆不要穿过别的组件（这一条没有检查，靠看样帧）。
- 箭头画在组件列表里它的位置上（后写的画在上面），一般写在两端组件后面。
