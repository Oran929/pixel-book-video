# 音色按书锁定，换音色只能整本书重新配音

项目有一个默认音色，新书默认使用它；只有在一本书开始前明确提出要用别的音色时，才在这本书的配置里覆盖。一本书第一次配音时，脚本把实际使用的音色设置（而不是"跟随默认"这个引用）写进 `books/<书>/voice.lock`，并提交到 git。之后每次配音前，守卫脚本会对比这本书当前算出来的音色和锁定音色；两者不一致就拒绝运行，除非用 `--revoice` 明确确认整本书重新配音。这样做是为了保证同一本书里不会混入两种声音。尤其是项目默认音色以后被改掉时，已经开始的书不能悄悄跟着变。

配音缓存放在各书自己的目录下（`books/<书>/cache/tts/`，不提交），文件名是"朗读文本 + 音色设置"的哈希值，所以只有改动过的旁白句会重新生成。
